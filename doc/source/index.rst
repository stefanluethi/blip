blip documentation
==================

**blip** is a lightweight web tracing tool for embedded systems. It visualises
live telemetry (values and log records) streamed from a target device, either
directly or through the Python ``bridge``.

This documentation is organised in three parts:

* :doc:`architecture/index` -- how the software is structured.
* :doc:`usage/index` -- how to install, run and use blip.
* :doc:`requirements/index` -- what the software must do, with traceability
  managed by `sphinx-needs <https://sphinx-needs.readthedocs.io>`_.

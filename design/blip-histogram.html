Histogram view

How the values of the checked traces spread over the shown window: bars on shared bins, in the trace colours. Built from the tokens in theme.rs at the app's size, with traces from the demo recording. Hover a bin to see its counts.

Bars of overlaid traces

The same window of robot/pose drawn three ways: heading spreads over the whole circle, x and y swing like sines and pile up at their turning points. All three share one set of bins, so a bin means the same value range for each trace.

Mean and ±σ markers

Off by default, turned on for all traces at once. Mean and σ are those of the samples in the window, the same samples the bars count; Plot's stats weigh each value by the time it holds, so they can differ for traces with irregular samples. Shown here on the bars of A.

Sideways, next to a plot

With the bars turned sideways the values run up the vertical axis, so the histogram can sit beside a plot of the same trace. Its count axis takes the place of the time axis, so with both cards in one row the plot areas start and end at the same height. motor.speed_rpm holds at 2400, 800 and 1800 rpm; each plateau becomes a peak.

Log counts and empty bins

Linear counts hide the few samples of the speed changes between the plateaus. On a log scale a bin of one sample must still show, and an empty bin must not pretend to be one.

Empty, single and crowded

What the view shows before there is anything to count, when all values are the same, with a fixed range that cuts values off, and in a narrow card with long names.

Properties

Sections named after what they hold, not after x and y, because turning the bars swaps the axes.

  • Bins: choice_row Auto, Number or Width; Number and Width open one field below (an integer, or a width in the unit of the traces). Range is range_rows, starting from the fitted range when it becomes Fixed.
  • Counts: only the scale; the count axis always fits the tallest bin in view.
  • Bars: Orientation and Markers, one choice each for all traces. No bar style choice: the chosen option is the style.
  • Number format comes for free (WRITES_VALUES): it writes the bin edges in the tooltip and the value ticks.

Recommendation

A, quiet bands, with the whisker strip of B for the markers. The wash under an outline is the state bands' look turned on its side: blip already says "a quiet tint with an edge in the full colour", so a histogram drawn that way belongs to the app on sight. One trace reads as a solid shape, three still read as three outlines, and overlaps only darken a little. Side by side bars are the loud option the brief warns about.

The whisker strip keeps the mean and spread off the bars, so turning markers on adds three short rows instead of nine lines across the data.

Sideways with the value axis on the left, the same 50 px numbers column as Plot, so a histogram alone or beside a plot reads like any plot. Fit auto values with Plot's 5 % margin so a sideways histogram beside an auto plot of the same trace lines up without a link. Log counts from half a decade below 1, so single samples show and empty bins stay empty.

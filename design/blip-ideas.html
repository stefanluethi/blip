blip design ideas

Each idea from the review, with the current look on the left and the proposal next to it. Built from the colours and fonts in theme.rs, at the app's size.

1Equal-width digits

These values change ten times a second. On the left the digits have their own widths, so units and decimals shift sideways. On the right every digit is equally wide, so only the changed digits move. Both use Fira Sans Light, as now.

2Regular instead of Light

The same panels at 13 px. Light strokes thin out on dark backgrounds and on screens without high density. Regular keeps the same calm look with more body.

3Selection that isn't trace blue

Now the selected view, the first trace, the open tab and the Live button are all blue, so a selected plot with one trace looks like blue on blue. A shows selection with a neutral frame and a raised title bar and keeps blue for Live. B keeps a coloured selection but moves the accent to teal, which is close to the green used for info and connected.

4Trace colours in the tree

A checked trace fills its checkbox with its colour in the selected view, so the tree doubles as the legend. The type marks move into a faint column on the right, so the names line up and read first. The arrows become Phosphor carets like everywhere else. In an XY view the x trace stays neutral, since it has no line of its own.

5Legend in the title row

The legend now covers the top of the plot, here right over acc[2]. In the title row it covers nothing, and it can show each trace's value at the cursor, which makes the Table view less necessary for a quick reading. The unit moves next to the title, so the rotated axis label is no longer needed.

6Quieter state bands

Bands get a light fill and a 2 px edge in the full colour, so states stay readable without dominating the screen. A false boolean is empty, so true reads as on. Log levels take the colours of the Log view: debug is violet in both places.

1–6All together

The Overview tab with every proposal: Regular weight, tabular digits, neutral selection, colour checkboxes for the selected Motor speed view, legends with values, and quiet bands. The cursor line at the live end is drawn faint, from the polish list.
